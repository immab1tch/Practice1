## 核心修正

令 `u_I,u_E,u_C=δ_I,δ_E,δ_C × available` 为三类**新增改善投入**；以下函数不计基础维护和单独列账的措施费用。

\[
g_k(u_k)=\eta_k L_k\left(1-e^{-u_k/K_k}\right),\qquad k\in\{I,E,C\}.
\]

其一阶导数正、二阶导数负，且收益有上限。默认 `K_I=0.15、K_E=0.15、K_C=0.08` 亿美元，对应1500万、1500万、800万美元；投入达到K时获得最大响应的63.2%。`L_I=0.5、L_E=0.9、L_C=0.8` 与原效率0.7/0.8/0.6相乘，得到最大容量提升35%、最大生态压力削减72%、最大社会压力削减48%。**这些是可替换的结构假设，没有实测拟合依据；不是保证的工程效果。**

\[
I=I_0(1+g_I),\quad C_{env}=C_{env}^{raw}(1-g_E),\quad C_{soc}=C_{soc}^{raw}(1-g_C).
\]

原始压力沿用第一轮的游客规模、日峰值和措施通道。基建压力仍为 `0.6(x/I)^2+0.4(xd/2)`。相比线性生态抵扣，新式不会将环境压力抵成负数，也不会给无限投入无限收益。

居民接受度：

\[
S=\operatorname{sigmoid}\left[\operatorname{logit}(S_0)-\gamma(C_{soc}-1)\right].
\]

默认 `S0=0.7，γ=2`，基准压力为1时S=0.7；社区直接降低社会压力，随后平滑改善S，不再提前截断成1。营销不再额外免费增加S，仅保留原需求乘子。社区没有在S中重复增加第二份直接收益。`S_min=0.7` 是“不低于该参考状态”的软阈值，不能与第一轮基准为1的0.9阈值直接作高低比较；另外检查严格接受度情景，仍需要真实居民调查校准。

需求保持 `x=x0(τ/τ0)^ε(I/I0)^α(S/S0)^β∏(1+κm)`，每次以Brent法联立求根并核验残差；无干预基准严格回代 x=160、R=3.75、S=0.7、三个压力=1。

## 维护与预算：不强制新增投资占比

从2023年2月官方FY24预算提案选取服务规模作为维护代理：步道/开放空间/公厕441,900美元，加街道清理修缮200,000美元，基建基础服务共641,900美元；急救/EMS服务613,400美元作为社区公共服务代理。它们是**预算提案中的部分服务**，不是全部朱诺维护需求，也不是已核实的实际支出；未做跨年度通胀调整。将其作为本模型必须预留的基础服务是本次分析假设，另外用预留归零的对照检验。

- `total`：`u_I+u_E+u_C+措施年化费用+维护预留 ≤ 0.8 B`。
- `incremental`：`available=max(B−B0,0)`，仅新增支出和措施费用计入 `0.8 available`。基础维护假定原有预算继续承担，单独展示，不重复收费。
- 新增支出下界仍为0，未设10%、20%等最低配额。`total_I/total_C` 才含基础维护；`spend_I/spend_C` 是自由优化的改善投入。
- 基础维护维持参考系统，不产生本模型额外扩容、生态或居民改善效益。所有新增改善与单独措施费用必须互不重叠，岸电不能再作为生态改善投入重复计算。
- 税费收入τR是模型综合杠杆；并非法定统一税率。年化岸电成本仍不能证明首年现金流可行。

## 实验覆盖

- 3个随机种子、各180个体×160代NSGA-II，随后32种措施组合×4起点SLSQP精修。用三个非负辅助变量表示接受度、收入、社会压力的缺口，避免max罚项在阈值处造成数值折点；实际评分仍按真实缺口重算。
- 预算与机制对照：取消维护预留、仅新增税费、关闭社区收益、关闭全部投资收益（对于完全零收益的通道，在等评分解中选择零支出）；不同目标权重与重算熵权；居民软阈值提高到0.9的严格情景。
- 12个参数各±10%，同时输出固定政策和重新优化结果。负弹性×1.1代表绝对值增大。
- 600组联合扰动：ε均匀[-0.8,-0.2]；η_I/E/C分别[0.5,0.9]/[0.6,0.95]/[0.4,0.8]；K独立乘[0.7,1.3]；峰值系数乘[0.9,1.1]；措施成本乘[0.8,1.2]。独立均匀分布是压力测试设计，不是估计的参数分布；可行样本占比不是现实成功率。
- 49×49局部政策切片（税费、基建与生态份额转移）；保留不可行掩码。
- 总投入份额不变的小额资金转移诊断；需求与税费收入随政策联动，实际金额和预算余额也可能变化，名义转移0.1百万美元不保证新均衡下美元转移完全相等。

## 仍然不应过度解释

没有把三个正投入当作真实性证明：它们依赖饱和尺度与响应上限。优先核实这些参数，特别是生态投入是否确实具有给定减压效果、社区项目如何影响居民生活。满额预算政策通常对成本增长敏感；本次做了压力测试，但没有把期望最优伪装成鲁棒最优。居民指数不是调查满意率，生态指数不是CO2吨数或冰川退缩率。
