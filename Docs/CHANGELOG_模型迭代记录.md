## v7.0（2026-10-26，当前权威版）— 需求均衡与资金账本重构

**触发原因**：v6.1 把 160 万游客当自由变量在 [0,160] 枚举，又叠加"收入下限 3.6 亿硬约束 + 线性投资抵扣"，导致优化器被人为锁到上限（153.6 万、Pareto 退化、贴阈值）；权重、归一化、预算三处口径也不一致。

**9 组核心修改（详见《模型建立_修改点清单.pdf》23 条）**：
1. **任务边界**：M1 是给定容量/接受度下的"最优客流−政策组合"；M2 是资金账本（非鲁棒 MILP）；M3 加 Minimax Regret；M4 半定量 AHP-熵权 TOPSIS；M5 引力模型（非 MILP）。
2. **需求闭环**：游客量内生均衡（Brent 法），不再自由枚举；x 是结果不是输入。
3. **日峰值**：派生为 xd=x/80（=2.675·x/214），不再独立决策。
4. **游客成分**：客流↔旺季压力、居民↔噪声压力（旺季 50%/噪声 30%；游客 60%/居民 40%）。
5. **投资函数**：改边际递减饱和 g_k=η_k L_k(1−e^(−u_k/K_k))；K=(.15,.15,.08)、L=(.5,.9,.8)、η=(.7,.8,.6)。
6. **居民接受度**：sigmoid(logit S0−γ(C_soc−1))，S0=0.7、γ=2；m5 营销不再免费加 S。
7. **资金账本**：总预算制，先扣维护预留（0.6419/0.6134 百万），再分三类，支出≤0.8B；补 2024 真实值（τ=11%、税收 0.195B）；措施成本按 FY24/FY25 官方文件重估（岸电 0.0478、交通 0.0036 亿美元）。
8. **约束重分级**：14 硬 + 3 软（E_max=1.0 硬；S_min=0.70、R_min=3.45、H_max=1.0 软，罚 λ_S=5/λ_R=5/λ_H=2）。
9. **推荐与敏感性**：推荐 147.2 万 / τ=14.72% / m=01110；12 参数±10% 全弹性 |S_p|<1；600 蒙卡硬可行率 40.8%；49×49 切片；严格 S_min=0.9 情景另算。

**v7.0 已验证产出**：M1 主实验（479 可行政策、48 敏感性行、600 蒙卡、15 图，validation PASS）+ 收入下限专项核查（902 行回代、最大残差 2.56e-10，verification PASS）。
