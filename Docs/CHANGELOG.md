## 二、版本演进（为什么改，不是改了什么）

### v1.0 → v2.0（2026-10-21 上午）

- **跑模发现**：S00 最优解 R=3.4543 贴在 R_min=3.45 底线（"收入贴底"）；E_max=1.0 / S_min=0.9 超出预处理 CSV 区间 [0.6,0.95] / [0.4,0.7]；E_max 弹性全为 0。
- **裁定**：R_min 3.45→3.6（逼提税）、E_max→0.95、S_min→0.70、λ_R 1.0→10.0。
- **公式新增**：M1-2' 需求式乘环境吸引力因子 `(C_env,0/(C_env+0.1))^γ`（γ=0.1）；M1-4' C_env 地板 `max(0.5, 原式)`。
- **结果**：S00 R=3.645、τ=0.15、C_env=0.500、x=155.52 万。

### v2.0 → v3.0（2026-10-23 上午）

- **跑模发现**：M2（反哺）与 M1 口径不一致——M2 的 S_s≡1.00 恒成立（无游客规模反馈）；C_env,s=0.782 不含游客压力项；M2 中 c_unit 与 η 弹性完全相同（成本不进目标函数）。
- **裁定**：补 M2-4''（S_s 含规模反馈 `S₀−s_x·x/x₀`）、M2-4'''（C_env,s 含 M1-4' 规模项）；M2-6' 目标加 `−λ_cost·Σc_k y_k`（λ_cost=1.0）。
- **学术转化**：C_env Sobol 爆炸（ST=15.9/333）被论证为"方差退化 → 非活跃约束（Inactive Constraint）"，KKT 影子价格为 0。
- **结果**：72/256 组合可行，y\*=10100000，z=0.2666。

### v3.0 → v5.5 指南（2026-10-23 下午）

- **跑模发现**：求解器频繁 Infeasible；目标函数被 C_soc≈2844 的巨大绝对值主导（量级崩坏）；M5 分式约束 `x_i/cap_i` 含 0-1 变量在分母导致 MILP 求解器崩溃。
- **方向调整**：废弃非线性结构，全部转化为可秒解的 MILP 或外层枚举。

### v5.5 → v6.0 定稿（2026-10-23，当前基准）

- **M1 量级归一化**：C_soc ÷2844、C_inf ÷1137，所有目标项回到 [0,1]。
- **M1-7 改增量形式**：`S = 1.0 − 0.3(x/x₀−1) − 0.1(x_d/x_d0−1)(1−0.4m₄) + η_C·δ_C·B/B₀ + 0.1m₅`，基准态严格 S=1.0（根治 v2.0 基准偏移问题）。
- **M1-11 新增船数物理约束**：`x_d ≤ 0.4·n_s，n_s ≤ 5 整数`，堵求解器把日峰值压 0 的漏洞。
- **M1-9 改硬约束**：R≥3.6、Σδ≤0.8 不可违背；仅保留 S 软罚 `−5.0·max(0, 0.7−S)`。
- **M1-4 公式重构**：地板 0.5→0.4、基准 1.0→0.8、权重 0.5/0.5、措施系数 0.3。
- **M2 项目缩减**：8 个项目 → 3 类（y_I/y_E/y_C），2³=8 枚举；量纲乘 ω 转亿美元。
- **M3 砍 Sobol**：删除 SALib，改单因素弹性 ±10% 循环。
- **M5 纯线性化**：需求一阶泰勒展开 `x_i = x_i0·(1−0.5(τ_i−τ₀)/τ₀)`；约束全线性；w_H=10.0、w_B=5.0。
- **M4 定性降级**：不写优化代码，3×3 AHP 手算权重，两句话结论（威尼斯重税收、朱诺重生态）。
