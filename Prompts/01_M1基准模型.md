# Prompt 01 — M1 基准模型（第一步，核心任务）

```
任务：实现并跑通基准模型 M1 —— 多目标混合整数非线性规划
（MINLP, Mixed-Integer Nonlinear Programming）。
脚本保存为：Code\juno_project\m1_solver.py

## 输入
- preprocessed\juno_main_preprocessed.csv：15 个情景（S00-S14），含 x0（游客量）、R0（收入）、
  tax_rate（τ0）、delta_I/E/C（支出比例 δ）、权重列 w_income/w_env/w_soc/w_infra 等
- preprocessed\juno_measures_binary.csv：措施 m1~m5 的 0-1 表（日上限/酒类/岸电/交通/营销分流）
- 公式与参数：Docs\模型建立.pdf 第 3 章（M1-1 ~ M1-3 及目标/约束）、
  Docs\to编程手.pdf 第 2.1 节与第 4 节默认参数包

## 实现要求
1. 离散层：对 m1~m5 的 32 种 0-1 组合（2^5）外层 for 循环全枚举；
   每种组合下用 scipy.optimize.minimize(method="SLSQP") 优化连续变量 (x, τ, δ)。
2. 内生循环：公式 (M1-1)~(M1-3) 中 x 与税收 B、基础设施容量 I_cap 存在循环依赖，
   用不动点迭代（fixed-point iteration）：x0=160 → 算 B, I_cap, S → 代入需求式 (M1-2) 更新 x，
   直至 |x_new - x| < 1e-3 收敛。
3. 约束容错：若某组合 Infeasible，按「生态阈值 → 容量/5艘 → 预算 → 居民接受度」顺序放宽；
   每个情景 try-except，记录冲突的约束名与放宽过程（日志文件或结果表新增列），
   禁止静默丢弃或强行凑可行。
4. 参数集中管理：文件顶部 DEFAULT_PARAMS dict（epsilon=-0.5, alpha=beta=0.2, delta_total=0.8,
   eta_I=eta_E=eta_C=0.7, E_max=1.0, S_min=0.9，kappa 措施乘子 m1=-0.1/m2=-0.05/m3=+0.02/m4=+0.03/m5=+0.1），
   与 juno_params_scenarios.csv 的区间交叉校验；参数要能被 M3 敏感性分析直接 import 复用。
5. 目标：先用加权和（weighted sum，权重取 CSV 的 w_* 列）跑通；代码中预留 NSGA-II（pymoo）多目标接口，
   本轮不必实现。

## 输出（写入 results\m1\）
1. m1_results.csv：scenario_id, m1~m5(0/1), x, tau, delta_I/E/C, R, C_env, C_soc,
   feasible_flag, objective_value
2. pareto_income_env.png：收入 vs 环境成本散点（32 组合/前沿，标出选中折中解）
3. pareto_income_soc.png：收入 vs 社会成本散点（同上）
4. run_log.txt：每个情景的求解状态、放宽记录、耗时

## 验收标准
1. S00_baseline 情景：收入 R ≈ 3.75 亿美元，游客量 x ≤ 160 万（且收敛稳定）。
   若量级不对，先自查公式/迭代逻辑，再报告建模手，禁止改参数硬凑。
2. 15 个情景全部跑完，给出可解/不可解清单及原因。
3. 完成后输出：结果摘要（重点 S00）、每情景耗时、遇到的问题与处理方式。
```
