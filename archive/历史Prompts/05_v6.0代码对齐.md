## 模块一：M1 基准模型重构（`m1_solver.py`）

### 当前问题
代码停在 v2.0/v3.0，与 v6.0 有以下硬差距：

### 必须修改的 7 处

**① C_env 公式（M1-4）改为：**
```
C_env = max(0.4, 0.8 * (0.5*x/x0 + 0.5*(x_d/x_d0)*(1-0.3*m3)) - eta_E*delta_E*B/B0)
```
- 地板：0.5 → **0.4**
- 基准系数：1.0 → **0.8**
- 措施项：`(1-0.3*m3)`（原代码可能没有或系数不对）

**② C_soc 归一化（M1-5）：**
```
C_soc = (1/2844) * (0.5*(x/P)**2 + 0.3*(x_d/x_d0)*(1-0.4*m4) + 0.2*(1-0.2*m2))
```
- 必须除以 **C_soc,0 = 2844**，否则目标函数被巨值主导。

**③ C_inf 归一化（M1-6）：**
```
C_inf = (1/1137) * (0.4*(x/I_cap)**2 + 0.2*(x_d/x_d0))
```
- 必须除以 **C_inf,0 = 1137**。

**④ S 改增量形式（M1-7）：**
```
S = 1.0 - 0.3*(x/x0 - 1) - 0.1*(x_d/x_d0 - 1)*(1 - 0.4*m4) + eta_C*delta_C*B/B0 + 0.1*m5
```
- 基准态（x=x0, x_d=x_d0, δ=0, m5=0）严格 **S=1.0**。
- 原代码如果基准态 S≠1.0，必须修正。

**⑤ 新增船数约束（M1-11）：**
```
x_d <= 0.4 * n_s
n_s <= 5
n_s 为正整数（Z+）
```
- 这是 0-1 措施之外的新整数决策变量 `n_s`。
- 外层枚举时，n_s ∈ {1,2,3,4,5} 也要枚举进去。

**⑥ 硬约束（M1-9 / M1-10）：**
```
C_env <= 0.95
0.09 <= tau <= 0.15
R >= 3.6           # 亿美元
delta_I + delta_E + delta_C <= 0.8
delta_I, delta_E, delta_C >= 0
```
- R≥3.6 是硬约束，不是软罚。

**⑦ 目标函数（M1-13）：**
```
max J = 0.4*R/R0 - 0.3*C_env - 0.2*C_soc - 0.1*C_inf - 5.0*max(0, 0.7 - S)
```
- 权重：w_R=0.4, w_E=0.3, w_S=0.2, w_I=0.1（和为 1）。
- 只有 S 保留软罚（系数 5.0），其他全是硬约束。

### 求解方式
- 外层枚举：m_j ∈ {0,1}（2^5=32 组合）× n_s ∈ {1..5}（5 个）= 160 组。
- 每组内层：对 (x, x_d, τ, δ_I, δ_E, δ_C) 做不动点迭代（需求 M1-2 与状态 M1-3~M1-7 耦合）。
- 基准态校验：S00（m=00000, δ=0, τ=0.11）必须回代到 x≈160, R≈3.75, S=1.0。

### 输出
- `results/m1/m1_results.csv`：所有可行组合的 (m, n_s, τ, x, x_d, R, C_env, C_soc, C_inf, S, J)。
- `results/m1/run_log.txt`：S00 基准态回代校验值 + 最优解。

## 模块二：M2 鲁棒反哺模型重构（`m2_robust.py`）

### 当前问题
- 项目数不对（原代码可能 8 个项目）。
- 量纲未统一（ω 系数缺失）。
- 蒙卡预算可行率 0% bug。
- C_env,s 超 E_max、x_new 方向矛盾。

### 必须修改

**① 项目缩减为 3 类（M2-1）：**
```
y_I, y_E, y_C ∈ {0,1}
```
- 外层枚举 2^3 = **8 种组合**，不是 2^8。

**② 资金注入与状态反馈（M2-2 ~ M2-5）：**
```
delta_k_s = delta_k * y_k          # M2-2
I_s = I0 * (1 + eta_I * delta_I_s)  # M2-3
C_env_s = max(0.4, 0.8*(0.5*x_s/x0 + 0.5*x_d/x_d0) - eta_E*delta_E_s)  # M2-4
S_s = 1.0 - 0.3*(x_s/x0 - 1) + eta_C*delta_C_s  # M2-5
```

**③ 情景需求更新（M2-6）：**
```
x_s_new = x0 * (tau_s/tau0)**epsilon * (I_s/I0)**alpha * (max(0.01,S_s)/S0)**beta * prod(1+kappa_j*m_j)
```

**④ 鲁棒目标（M2-7）：**
```
max z
s.t.  z <= sum_k(omega_k * delta_k_s) - lambda_cost * sum_k(c_k * y_k) - lambda_L * max(0, x0 - x_s_new)
      for all s in S (15 个情景)
```
- ω_I=0.5, ω_E=1.0, ω_S=0.8（转亿美元当量）。
- λ_cost=1.0, λ_L=0.05。
- 每种 y 组合下，取 15 个情景中 z 的最小值（最坏情况），再在 8 种 y 组合中取最大。

**⑤ 修 bug：**
- 蒙卡预算可行率 0%：检查预算约束 `sum(c_k*y_k) <= B` 是否写错（B 单位、c_k 单位）。
- C_env,s 超 E_max：M2-4 里 C_env 不能超过 0.95，超过的情景标记为不可行。
- x_new 方向：增税 τ↑ 应使 x↓（ε=-0.5），如果代码里 x_new 随 τ 上升而上升，检查符号。

### 输出
- `results/m2/m2_scenarios.csv`：8 种 y 组合 × 15 情景的 (x_s_new, C_env_s, S_s, z)。
- `results/m2/m2_projects.csv`：最优 y 组合、z 值、各项目投资金额。
- `results/m2/run_log.txt`：可行组合数、最优解、蒙卡统计。

## 模块四：M5 空间均衡模型重构（`m5_spatial.py`）

### 当前问题
- v_i 变量类型错误（应 0-1 二元，代码可能写成连续）。
- τ_i 决策变量失效（全输出 0）。
- w_H/w_B 参数差 10 倍/5 倍。
- 需求未泰勒展开。

### 必须修改

**① 需求泰勒展开（M5-2）：**
```
x_i = x_i0 * (1 - 0.5 * (tau_i - tau0) / tau0) + sum_j(f_ji) - sum_j(f_ij)
```
- 消除 (τ_i/τ0)^-0.5 的幂函数，改一阶线性。

**② 流量守恒与边容量（M5-1, M5-3）：**
```
sum_i(x_i) = x
0 <= f_ij <= F_ij
```

**③ 节点限流与边容量（M5-4 ~ M5-6）：**
```
x_i <= cap_i + delta_cap_i * v_i - delta_i * z_i        # M5-4
x_i <= H_max * (cap_i - delta_i * z_i)   for i in hot   # M5-5
x_i >= rho * (cap_i + delta_cap_i * v_i) for i in cold  # M5-6
```

**④ 变量类型：**
- v_i ∈ {0,1}（0-1 二元，不是连续 0-10）。
- z_i ∈ {0,1}（0-1 二元）。
- τ_i ∈ [τ_min, τ_max] = [0.09, 0.15]（连续）。
- f_ij ≥ 0（连续）。

**⑤ 目标函数（M5-7）：**
```
max sum_i(p0*(1+tau_i)*x_i) - w_H * sum_{i in hot}(x_i/cap_i) + w_B * sum_{i in cold}(x_i/cap_i) - sum_i(c_i*v_i)
```
- w_H = **10.0**（亿美元/无量纲）。
- w_B = **5.0**（亿美元/无量纲）。
- 这两个系数把无量纲的 x_i/cap_i 转成亿美元当量。

**⑥ 预算约束（M5-8）：**
```
tau_min <= tau_i <= tau_max
sum_i(c_i * v_i) <= B_spatial
```

**⑦ 修 bug：**
- τ_i 全输出 0：检查 τ_i 是否被正确声明为决策变量（不是常数），以及上下界是否设对。
- v_i 连续：改成 pulp.LpVariable(..., cat='Binary')。

### 输出
- `results/m5/m5_region_allocation.csv`：每个区域的 x_i, τ_i, v_i, z_i, f_ij。
- `results/m5/m5_objectives.csv`：目标函数值、各分项。
- `results/m5/run_log.txt`：求解器状态、守恒校验（Σx_i = x）。
