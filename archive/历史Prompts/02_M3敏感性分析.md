# Prompt 02 — M3 敏感性分析 + 论文图（跑完 M1 后执行）

```
任务：实现 M3 敏感性分析（sensitivity analysis）模块，
脚本保存为：Code\juno_project\m3_sensitivity.py
依赖：m1_solver.py 的目标函数与求解函数（import 复用，不要复制粘贴重写）。

## 输入
- m1_solver.py 及其结果 results\m1\m1_results.csv
- preprocessed\juno_params_scenarios.csv：参数名、取值、lower/upper 区间（ε, η_I, η_E, η_C, E_max 等）
- 公式依据：Docs\模型建立.pdf 第 5 章（M3）

## 实现要求
1. 单因素敏感性（局部）：对 ε、η_I、η_E、η_C、E_max 逐个做 ±10% 扰动（其余固定基准值），
   复用 M1 求解，计算弹性 S_p = (ΔY/Y) / (Δp/p)，Y 分别取收入 R、环境成本 C_env、社会成本 C_soc；
   输出弹性排序表（谁对结果影响最大）。
2. 全局敏感性：用 SALib（Saltelli 采样）计算 Sobol 一阶指数 S1 与总效应指数 ST（first-order &
   total-order indices），抽样 500 次；参数范围取 juno_params_scenarios.csv 的 lower/upper。
3. 交互效应：Sobol 二阶项或一阶/总效应对比，判断是否存在强交互。
4. 性能：每次抽样调用 M1 前先检查是否可复用缓存（如对同一参数组合只求一次）；
   如果 500 次 × 32 组合跑不动，允许先对 S00_baseline 单情景做 Sobol，并在报告中说明口径。

## 输出（写入 results\m3\）
1. m3_elasticity.csv：参数、±10% 前后各目标值、弹性值
2. sobol_indices.csv：参数、S1、ST（如有则含置信区间）
3. 图（300 dpi、中文字体）：
   - sobol_bar.png：Sobol 指数柱状图（S1/ST，误差棒）
   - elasticity_rank.png：弹性绝对值排序条形图
   - interaction_heatmap.png：参数交互热力图（可选）

## 验收标准
1. 所有图/表命名与结果口径和模型文档一致，可直接放进论文「敏感性分析」小节。
2. 给出 3 条结论句：哪些参数对收入/环境/社会目标最敏感、是否存在交互、对政策建议（如限流、税率）
   意味着什么。
3. 报告计算耗时与抽样规模，说明 Sobol 是否覆盖全部情景或仅 S00。
```
