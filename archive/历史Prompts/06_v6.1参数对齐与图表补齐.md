## 三、M5 升级（`m5_spatial.py`）

### 3.1 改参数

| 参数 | v6.0（当前代码） | v6.1（必须改为） |
|---|---|---|
| w_H | 10.0 | **2.0** |
| w_B | 5.0 | **1.0** |

### 3.2 加防关停约束（v6.1 新增）

热点区域游客量下限，防止求解器把热点关停：
```
x_i >= 10,  for all i in I_hot
```
对应 v6.1 M5-6 第三行约束 `x_i ≥ 10 (防止求解器强制关停)`。
v6.0 代码里 R2(hot) x=0 是 w_H=10 造成的，改 w_H=2.0 + 下限后必须消失。

### 3.3 τ_i 离散化（把固定值变成决策变量）

v6.0 代码把 τ 固定为 0.09（因为 τ·x 是二次项，PuLP MILP 不支持）。v6.1 细则要求：
- 将 τ_i 离散化为三档：**τ_i ∈ {0.09, 0.12, 0.15}**
- 每个区域 i 引入 3 个 0-1 选择变量，或等价地用 PuLP 的 LpBinary + 大 M 方式实现"选一档"：
  - 目标函数里 τ_i·x_i 的乘积：把 τ_i 离散化后，可把每个候选 τ 档位做成带 0-1 开关的线性项（用 x_i 与档位选择变量相乘时，用大 M 线性化：`x_i - M*(1-s_ik) <= x_ik <= x_i + M*(1-s_ik)`，其中 Σ_k s_ik = 1）。
- 目的：τ_i 真正成为优化变量，M5 输出"差异化税率表"（不同区域税率不同），而不是全场 0.09。

### 验收

- R2(hot) x > 0（防关停生效）。
- 至少两个区域的 τ_i 不同（差异化税率产生）。
- 守恒校验 Σx_i = x 仍为 0% 误差。
- 求解状态 Optimal。
